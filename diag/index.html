READ-ONLY · CANNOT MODIFY ESC
This page is NOT in a secure context — the browser will not expose Web Serial here (plain http on a LAN IP). To capture: plug the ESC's USB dongle into this machine, then open this page over https, or at http://127.0.0.1:3180 (or http://localhost:3180), instead of the 192.168.4.229 address, and come back to this tab. If your browser is on a different machine, plug the dongle into that machine and open this page's localhost address there.

Connection

disconnected
Plug the USB linker into the ESC signal lead, power the ESC with a battery, then hit Connect. This tool only ever sends READ commands — there is no write, no flash, no settings path anywhere in it.

Capture

Captures: bootloader handshake info, firmware name string, the full 192-byte EEPROM/settings block, all Rockwolf diagnostic bytes, and (optionally) the whole application image hashed against every known shipped build. Everything is decoded into a report you can save or copy.
